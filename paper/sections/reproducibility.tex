\section{Reproducibility}
\label{app:repro}

\paragraph{Code, data and build.} The repository holds the C++ core, the Python
layer, every configuration, every result file and this paper's sources. One
command regenerates the numbers, tables and figures from the result files and
compiles the paper: \texttt{python paper/build.py}; adding \texttt{--analysis}
first reruns every analysis from the per-seed files. Release v2.0.0 is archived on
Zenodo, under the concept DOI 10.5281/zenodo.23620786.

\paragraph{Pre-registration.} The repository's pre-registration file is append-only,
and each experiment is named by its entry there (R2-E9 and so on). Every
experiment of Table~\ref{tab:experiments} except the post-hoc rows was registered
at commit \texttt{\regCommit}; the warm-start primary measure at
\texttt{\regCommitWarm}, written after the four candidate measures had been
computed on earlier five-seed data, and saying so; the three post-hoc checks at
\texttt{\regCommitCheckB} and \texttt{\regCommitCheckC}; and one execution failure,
before any of its data existed, at \texttt{\regCommitRepair}. That failure was a
configuration value written without a decimal point, which the configuration
reader parsed as text, so all fifty floating-point-sensitivity runs stopped before
computing anything and were rerun unchanged in design.
Table~\ref{tab:predictions} scores every registered prediction.

\paragraph{Thread count.} Every run is at one thread. The ranker's training is
not bitwise reproducible across thread counts, because the order of floating-point
reductions changes, and \S\ref{sec:design} shows how far a difference of that size
travels. A test fails if a configuration sets a thread count other than one for a
quoted run.

\paragraph{Run records.} Each seed of each experiment wrote a record of the
commit it ran from, whether that tree was clean, the full configuration and its
hash with the seed removed, the library versions and the wall time. The analysis
scripts refuse a directory whose records disagree on commit or configuration
hash. Table~\ref{tab:experiments} is built from these records.

\paragraph{Archived directories.} Results produced before the experiments of
Table~\ref{tab:experiments} are kept in the repository and labeled archival; no
number in this paper comes from them. The 300-round run of the shipped
configuration in the project's first release does not regenerate from the current
code at any thread count from 1 to 24, in its NCF arm only, and that release's
twenty-seed 100-round run differs from a fresh run in the fourth decimal. A later
300-round five-seed run at one thread reproduces exactly: seeds 42 to 46 of the
canonical run match it to every printed digit. The earlier institutional grids,
warm-start runs and sweep were read at horizons or seed counts that the
experiments of Table~\ref{tab:experiments} replace.
