\section{Reproducibility}
\label{app:repro}

\paragraph{Code, data and build.} The repository holds the C++ core, the Python
layer, every configuration, every result file and this paper's sources. One
command regenerates the numbers, tables and figures from the result files and
compiles the paper: \texttt{python paper/build.py}; adding \texttt{--analysis}
first reruns every analysis from the per-seed files. Release v2.0.0 is archived on
Zenodo, under the concept DOI 10.5281/zenodo.23620786.

\paragraph{Pre-registration.} The repository's pre-registration file is append-only.
Every experiment of the second revision was registered at commit
\texttt{\regCommit}; the warm-start primary measure at \texttt{\regCommitWarm},
written after the four candidate measures had been computed on earlier five-seed
data, and saying so; the three post-hoc checks at \texttt{\regCommitCheckB} and
\texttt{\regCommitCheckC}; and one execution failure, before any of its data
existed, at \texttt{\regCommitRepair}. Table~\ref{tab:predictions} scores every
registered prediction.

\paragraph{Thread count.} Every run is at one thread. The ranker's training is
not bitwise reproducible across thread counts, because the order of floating-point
reductions changes, and \S\ref{sec:design} shows how far a difference of that size
travels. A test fails if a configuration sets a thread count other than one for a
quoted run.

\paragraph{Run records.} Each seed of each experiment wrote a record of the
commit it ran from, whether that tree was clean, the full configuration and its
hash with the seed removed, the library versions and the wall time. The analysis
scripts refuse a directory whose records disagree on commit or configuration
hash. Table~\ref{tab:experiments} is built from these records.

\paragraph{Directories from earlier revisions.} Results produced before this
revision are kept and labeled archival; no number in this paper comes from them.
A 300-round run of the shipped configuration produced two revisions earlier does
not regenerate from the current code at any thread count from 1 to 24, in its NCF
arm only. A twenty-seed 100-round run from the same period differs from a fresh
run in the fourth decimal. A 300-round five-seed run produced in the previous
revision at one thread reproduces exactly: seeds 42 to 46 of this revision's
canonical run match it to every printed digit. The previous revision's
institutional grids, its warm-start runs and its sweep were all read at horizons
or seed counts this revision replaced, and are superseded by the experiments of
Table~\ref{tab:experiments}.
