# Ablation data

Generated by `scripts/run_ablation.py` on 2026-10-19, committed so the figures
quoted in the README and in THEORY.md §7.7 can be checked without re-running the
simulation.

    python scripts/run_ablation.py --seeds 42,43,44,45,46

That command read `experiments/base.yaml` while it shipped `admissible_fraction: 0.2`,
at a 20-epoch horizon. Since Session 4-A the file ships 0.02 and `n_epochs: 100`, so
reproducing these tables needs both pinned: a copy of base.yaml with
`population.admissible_fraction: 0.2`, passed as `--config`, plus `--epochs 20`.

## Regime

This is the **inert-loop regime**: `population.admissible_fraction: 0.2`, at which
the θ gate never truncates and the market does not respond to its own clearing
outcomes. THEORY.md §3 states the condition for the gate to bind
(`phi < 2k/N`, i.e. below 0.04 at k=20, N=1000) and records both measured regimes.

Session 4-A changed the default to 0.02 and re-ran this sweep into
`data/processed/ablation_live/`. Both directories are kept deliberately: the
difference between them is the evidence that feedback matters, and a single
directory would make that comparison impossible after the default changed.

## Files

| file | contents |
|---|---|
| `<arm>_seed<seed>.csv` | one row per epoch, the full metrics table |
| `summary.csv` | mean and sd of each metric, per arm, over the five seeds |
| `gaps.csv` | the per-seed differences between arms, mean and sd |

## Thread count

**24, verified.** This directory predates `ncf.num_threads`, so the count was whatever torch took
from the machine and the development machine reports 24. Re-run on 2026-10-25 with
`admissible_fraction: 0.2`, `--epochs 20` and `ncf.num_threads: 24`, the `ncf` arm for seed 42
reproduces its 20 rows of `ncf_seed42.csv` exactly, epoch-19 Gini 0.9415702 included. At the
shipped default of 1 it does not.

The thread count matters only for the `ncf` arm. The `oracle`, `random` and `popularity` arms train
no model and are bitwise identical at every thread count, so on those three the count can be left
unset without affecting reproducibility.

To regenerate exactly, set `ncf.num_threads: 24` alongside the two pins named at the top of this
file (`admissible_fraction: 0.2` and `--epochs 20`). The shipped default of 1 remains correct for
new work.

## Quoting these numbers

Every figure is a mean ± sd over five independent populations, never a single run.
The seed spread says the simulation is stable, not that the result generalizes —
it is a statement about the model, and the model has no empirical calibration.
See THESIS.md for what these results can and cannot support.
