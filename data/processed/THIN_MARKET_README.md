# Thin-market data

Generated by `scripts/run_thin_market.py`, committed so the THEORY.md §10.5 tables
can be checked without re-running the sweep.

Three directories, one per acceptability bar:

| directory | bar | critical mass N* (rho = 0.5) |
|---|---|---|
| `thin_market/` | each agent's own θ (0.8 quantile) | 3.1 |
| `thin_market_q0.95/` | each agent's 0.95 utility quantile | 13.3 |
| `thin_market_q0.99/` | each agent's 0.99 utility quantile | 65.6 |

The θ bar is nearly vacuous — any pool of a few dozen clears it — so the two
quantile bars exist to make pool size matter. The `clearance_prob` column is the
same in all three: the bar only changes the acceptability columns.

## Reading the clearance curve

Clearance rises, peaks near 0.55 at |B| ~ 194, then falls. **Only the rise is the
thin-market penalty.** The fall comes from truncating preference lists at k = 20,
and disappears as k grows (at 500 per side: 0.270 at k = 20, 0.944 at k = 200).
Do not quote this curve as support for H4 in THESIS.md; THEORY.md §10.5 explains
why.

## Files

`curve_seed<seed>.csv` per seed (42–46), `curve_mean.csv` averaged over seeds, with
`clearance_sd` giving the spread between seeds. Epoch 0 only: θ as calibrated, no
feedback.
