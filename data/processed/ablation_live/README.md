# Ablation data, live-gate regime

Generated by `scripts/run_ablation.py` on 2026-10-21 (Session 4-A), at the shipped
`population.admissible_fraction: 0.02`:

    python scripts/run_ablation.py --seeds 42,43,44,45,46 --epochs 20 \
        --output-dir data/processed/ablation_live

`--epochs 20` matches the horizon of `data/processed/ablation/`, so the two
directories differ in one parameter only.

## Regime

This is the **live-gate regime**: phi = 0.02 < 2k/N = 0.04, so at epoch 0 every agent's
admissible set (about 10 candidates) is shorter than the k = 20 shortlist and θ decides
who is swiped on. `data/processed/ablation/` is the same sweep at 0.2, where θ never
binds. Keep both: the difference between them is the measurement of whether feedback
matters.

What the comparison shows, in THEORY.md §3 and §7.7: the gate binds at the start and
relaxes within a few epochs, because the θ update pulls θ toward a yield in [0, 1] from a
calibrated value near 7.5. The trajectories differ; the final-epoch ncf-minus-oracle gap
does not (+0.2867 ± 0.0101 live, +0.2849 ± 0.0074 inert).

## Quoting these numbers

Every figure is a mean ± sd over five independent populations, never a single run.
The seed spread says the simulation is stable, not that the result generalizes.
See THESIS.md for what these results can and cannot support.
