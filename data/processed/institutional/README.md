# Institutional comparison data

Generated by `scripts/run_institutional.py` (about ten minutes at N = 1000 over five
seeds), committed so the THEORY.md §10.4–§10.6 tables and the README findings can be
checked without re-running the comparison.

## Files

| file | contents |
|---|---|
| `grid.csv` | one row per (signal_cost, size_fraction, seed): both accountings, both environments |
| `grid_summary.csv` | the same, mean and sd over seeds |
| `values_min.csv`, `values_min_summary.csv` | the entry-filter axis at size_fraction 0.5, c_B = 0.01 |
| `factorial.csv` | the four cells of the drift × mediation decomposition, and the three terms, per seed |

## Which welfare column to quote

- **`welfare_diff_residual`** — the conservative headline. A is re-run on the agents B
  left behind.
- `welfare_diff` — THEORY §10.4's literal rule. It double-books agents whose full-A
  partner B matched (up to 49 per cell), so it overstates B.
- `welfare_selection_artifact` — selected minus common. **Negative in 172 of 200 cells**;
  it is not the non-negative diagnostic the original spec assumed.

The residual figure usually sits below the literal one but is not a strict lower bound:
one cell of 200 has it above (c_B = 0.25, size_fraction 0.05, seed 45).

## What these support, and what they do not

Environment A here is the **oracle** arm, so the comparison is between two institutions
with nothing estimated. Against an NCF-mediated A the ordering changes completely.

- **H4** survives at c_B = 0.01 only. Killed at c_B ≥ 0.05.
- **H5**'s interaction is indistinguishable from zero (t = 0.93 on 4 df).

The defection penalty `d` is charged after a match dissolves and changes no decision, so
these figures price defection without modelling deterrence. See THESIS.md.

## Thread count

**24, verified, and the count cannot matter: this directory trains no model.**
Environment A is the `oracle` arm and Environment B is the `complete` arm, neither of
which runs the NCF, so no torch reduction is involved and no thread count can change a
number (see `docs/INTERFACES.md` §3.1). The count is nonetheless recorded, because
these files also predate `ncf.num_threads` and the development machine reports 24.

Re-run on 2026-10-25, the `c = 0.01, size_fraction = 0.02, seed 42` cell reproduces
its `welfare_diff_residual`, `clearance_a`, `clearance_b`, `gini_a`, `gini_b` and
`n_eligible` exactly, at any thread count, provided the inert regime is pinned:
`admissible_fraction: 0.2`. At the shipped 0.02 the same cell does not reproduce,
because `run_institutional.py` reads the config as it stood in October and the gate
has moved since. That is a regime drift, not a thread effect, and the same is true of
`../separating/` and `../thin_market/`.

To regenerate exactly: `admissible_fraction: 0.2` and no thread setting needed.
